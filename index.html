Welcome & User Guide

This portal organises India's four consolidated Labour Codes into a structured, easy-to-navigate documentation format. Each code is broken down into multiple reading modes so you can access the information in the way that suits your role.

📋 Section-wise Legal Reference
Browse the bare legal text organised by section number — the authoritative reference.
💡 Concept-wise HR Guide
Topic-based explanations written for HR practitioners, not lawyers.
✅ Compliance Checklist
Actionable checklist of obligations, deadlines, and filings per code.
⚖️ Old Law vs Code Comparison
Side-by-side comparison of repealed Acts and their new Code equivalents.
🔍 HR Watchlist
Critical changes and risk areas that HR must monitor closely.
❓ FAQs
Frequently asked questions with concise, practical answers.

Navigation Guide

Top Navigation Bar — Use the fixed header to switch between the four Labour Codes or return Home at any time.

Sidebar — Within each Code, the left sidebar lists all reading modes. Click to switch sections.

Breadcrumbs — The trail at the top shows your current location. Click any segment to navigate back.

Tabs — Horizontal tabs organise sub-topics. Click a tab to switch content without leaving the page.

Accordions — Expandable sections reveal detailed content on demand. Click the header to expand or collapse. Nested accordions go one level deeper.

Cross-Reference Links — Section references (e.g., "Section 2(y)") are clickable hyperlinks that navigate directly to the referenced legal provision.

Related Links — The right panel lists provisions, checklist items and FAQs declared as related to the item you have open, followed by the same view in the other Codes.

Search — Use the search bar in the top-right. Every word you type must appear in a result (e.g. wages resignation); filter results by Code and content type; type a section number such as s 17 or section 17 to jump straight to it. Matches are highlighted.

Direct links — The address bar always reflects the page or item you are viewing, so you can bookmark it, share it, refresh, or use the browser's Back and Forward buttons.

All FAQs — The All FAQs view in the top bar collects the FAQs of every Code in one place; each Code's own FAQ tab is unchanged.

Reading Modes Explained

Each Labour Code is presented through multiple complementary views. Pick the one that fits your task:

Legal Reference — for precise statutory language and section numbers.
HR Guide — for practical understanding grouped by HR concepts.
Compliance Checklist — for audit-ready action items and deadlines.
Old vs New Comparison — for understanding what changed from earlier Acts.
HR Watchlist — for high-impact items requiring immediate attention.
FAQs — for quick answers to the most common questions.
